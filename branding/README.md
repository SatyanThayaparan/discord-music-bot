# Benji — Solarpunk brand kit

## Palette (60 / 30 / 10)

| Role | Name | Hex | Use |
|------|------|-----|-----|
| 60% Dominant | Warm Sand | `#F4EFE6` | Banner atmosphere, light surfaces |
| 30% Secondary | Deep Canopy | `#1E4D3B` | Foliage, embed bars, typography weight |
| 10% Accent | Solar Amber | `#F5A623` | EQ glow, queued embeds, highlights |

## Style

Minimal kawaii **music blob** mascot (cream body, canopy-green headphones, amber accents) — silly solarpunk, not ornate stained-glass.

## Assets

| File | Size | Discord upload target |

| [`benji-icon-512.png`](benji-icon-512.png) | 512×512 | App icon + Bot avatar |

JPG masters are also kept beside the PNGs.

## Upload in Discord Developer Portal

1. Open [Discord Developer Portal](https://discord.com/developers/applications) → your Benji app  
2. **General Information** → App Icon → upload `benji-icon-512.png`  
3. **Bot** → Icon → same file (bot avatar users see)  
4. **Bot** → Banner → upload `benji-banner-960x540.png`  
5. Optional: rename the bot display name if you want (e.g. keep **Benji**)  
6. Save changes — avatar/banner can take a few minutes to refresh in clients (Ctrl+R)

Embed colors in the bot already follow this palette via [`brand.py`](../brand.py).
