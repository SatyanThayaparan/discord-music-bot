Smoke checklist (private test server)
=====================================
Prereq: join a voice channel, then run .\run.ps1 (or .\dev.ps1)

1. Search picker
   !p overtaken epic
   Expect: embed with top results + dropdown; pick one; audio starts

2. Direct URL
   !p https://www.youtube.com/watch?v=dQw4w9WgXcQ
   Expect: queues or plays without picker

3. Panel / volume
   Use Vol − / Vol + on Now Playing (or !vol 50 / !vol 100)
   Expect: louder/quieter; panel shows Vol N%

4. Skip (must advance once only)
   !skip
   Expect: next song starts once (no double jump)

5. Seek
   !ff
   !rw
   Expect: same song continues from new offset (does not skip track)

6. Queue UX
   !q
   Expect: spaced queue listing / panel Queue + Back

7. Loop
   !loop
   !skip   (optional — should re-queue current when it ends)
   !unloop

8. Saved playlists
   !save smoke-test
   !playlists
   !clear
   !load smoke-test
   !delplaylist smoke-test
   Expect: save/load/delete without crash

9. YouTube playlist (yt-dlp, max 50)
   !playlist <youtube_playlist_url>
   Expect: N tracks queued, playback starts if idle

10. Teardown / idle
   !clear
   !stop
   Expect: no crash, bot leaves VC
   (Optional) leave Benji alone in VC ~5 min — should auto-disconnect
